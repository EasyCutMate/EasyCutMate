## 📲 How to install

📖 **[Read the full User Guide (PDF, with screenshots)](docs/EasyCutMate-User-Guide.pdf)**: installing, your account, every editing tool, and getting videos from links (YouTube, TikTok and more) without a watermark.

Use **Chrome**. Links opened inside WhatsApp, Messenger or Facebook often can't save app files: tap **⋮ → Open in Chrome** first.

1. Tap the download link above.
2. Chrome asks **"Choose where to download"**: tap **Download**.
3. Chrome warns **"File might be harmful"**: tap **Download anyway**. Every app from outside the Play Store gets this warning.
   - Download stuck at 100% and the file isn't in Files? One of these two pop-ups was missed. Open **Chrome ⋮ → Downloads**, tap the EasyCutMate entry and choose **Download anyway**, or delete it and tap the link again.
4. When it says **File downloaded**, tap **Open**, then tap **Install**.
   - If Android blocks it: tap **Settings → Allow from this source**, go back and tap **Install** again.
   - If Google Play Protect warns you: tap **More details → Install anyway**. This is normal for apps that aren't from the Play Store.
5. Open **EasyCutMate** and create your account (see below).
